# Arkiv – bruges ikke længere

`mirror.mjs` og `extra-assets.json` blev brugt til at lave den oprindelige kopi af Squarespace-siden (2026-09-20).
Squarespace er opsagt, og promilleplan.dk peger nu på GitHub Pages. **Kør ikke `mirror.mjs`**: den ville hente
siden fra promilleplan.dk, altså fra denne kopi selv, og overskrive filerne. HTML-filerne i roden er nu kilden.
